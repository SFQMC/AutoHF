User's Guide and API Reference
==============================

AutoHF is an autodifferentiation-based library for 
performing Hatree-Fock calculations on interacting electon systems.

See the `User's Guide <user/manual.html>`_ for more information on how to use AutoHF.

See the `API Reference <api/modules.html>`_ for detailed information on the modules and functions available in AutoHF.
