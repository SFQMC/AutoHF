.. _quickstart:

Quick Start Guide
=================

An AutoHF calculation typically consists of two steps.

1. Construct an :class:`autohf.AutoHFHamiltonian` from a set of onebody and interaction terms.
2. Find a Hartree-Fock solution by running :func:`autohf.solve_hf`.

The :ref:`user_examples` contain specific examples for how to do this for a variety of models.

The :ref:`api_reference` of the above functions documents all supported Hamiltonian terms and configuration settings, respectively.
